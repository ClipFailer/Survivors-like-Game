# Survivors-like Game 🧟‍♂️

**Учебный проект** — игра в жанре **survivor-like** (как Vampire Survivors, Brotato и другие), разработанная на **Unreal Engine 5** с использованием **Blueprints**.

Проект создан с целью изучения возможностей движка, отработки навыков программирования игровой логики и создания полноценного игрового цикла.

---

## 🎮 Суть игры

Вы управляете героем, который сражается с бесконечными волнами врагов. Цель — **выжить как можно дольше**, уничтожая противников, получая опыт и становясь сильнее с каждым уровнем.

Игра построена на классических для жанра механиках:
- автоматическая атака по ближайшим врагам;
- прокачка персонажа с выбором улучшений;
- постепенное усложнение волн;
- сбор ресурсов с поверженных врагов.

---

## ⚙️ Основные механики

| Механика | Описание |
|----------|----------|
| 🧟 **Волны врагов** | Противники появляются волнами с увеличивающейся сложностью. Каждая волна сильнее предыдущей. |
| ⚔️ **Автоматическая атака** | Герой автоматически атакует ближайшего врага. Игроку не нужно целиться — только двигаться и принимать тактические решения. |
| 📈 **Система опыта и уровней** | За убийство врагов начисляется опыт. При заполнении шкалы опыта герой получает новый уровень. |
| 🎯 **Выбор улучшений** | При повышении уровня игроку предлагается выбрать одно из нескольких случайных улучшений (увеличение урона, скорости, здоровья и т.д.). |
| ❤️ **Здоровье и регенерация** | У героя есть полоска здоровья. При получении урона она уменьшается. При потере всего здоровья игра заканчивается. |
| 🗺️ **Открытое поле** | Игрок свободно перемещается по уровню, выбирая тактику и уклоняясь от врагов. |

## 🛠️ Технологии

- **Unreal Engine 5**
- **Blueprints** — вся игровая логика реализована на визуальном скриптинге
- **Git LFS** — для хранения бинарных ассетов (`.uasset`, `.umap` и др.)

## 📥 Как скачать и запустить проект

### 1. Клонирование репозитория

```bash
git clone https://github.com/ClipFailer/Survivors-like-Game.git
cd Survivors-like-Game
```

### 2. Установка Git LFS
Проект использует Git LFS для хранения ассетов. Без него файлы не скачаются корректно.

Установка Git LFS:

Скачайте и установите Git LFS с официального сайта

Или через пакетный менеджер:

Windows (choco)
```bash
choco install git-lfs
```

macOS (brew)
```bash
brew install git-lfs
```

Linux (apt)
```bash
sudo apt install git-lfs
```

Инициализация LFS в репозитории:

```bash
git lfs install
git lfs pull
```

### 3. Открытие проекта
Убедитесь, что у вас установлен Unreal Engine 5 (версия 5.0 или выше).

Найдите в папке проекта файл SurvivorsLike.uproject.

Дважды кликните по нему — проект откроется в редакторе Unreal Engine.

При первом открытии может появиться предложение пересобрать модули — соглашайтесь.

### 4. Запуск игры из редактора
Нажмите кнопку Play в редакторе (или Alt + P).

Игра запустится в режиме предпросмотра.

📦 Сборка игры (Packaging)
Чтобы создать готовый .exe-файл для распространения:

В редакторе откройте File → Package Project → Windows → Windows (64-bit).

Выберите папку для сохранения собранной игры.

Дождитесь завершения сборки.

Готовый билд будет в выбранной папке — запускайте SurvivorsLike.exe.

## 📁 Структура проекта
```
Survivors-like-Game/
├── Config/          # Конфигурационные файлы движка
├── Content/         # Все игровые ассеты (Blueprints, текстуры, звуки, карты)
├── Source/          # Исходный код C++ (основные модули проекта)
├── .gitattributes   # Настройки Git LFS
├── .gitignore       # Исключаемые из репозитория файлы
└── SurvivorsLike.uproject # Главный файл проекта
```
